Project route / Five locks

## From first idea to final submission.

1. 01By 22 Sep


### Register


Create a team of 1–4 participants by 22 September at 23:59 WIB. Registration is free.

2. 02Before code


### Onboard


Every participant creates a Sectors account and completes onboarding before the team writes project code.

3. 03Locks the roster


### Claim API credits


Once every participant has finished onboarding, the representative claims the team's 1,000 Sectors API credits from the portal. Claiming locks the roster — no members can be added or removed afterward.

4. 0419 Aug – 30 Sep


### Build


Choose one track and make Sectors data a core source for your working project.

5. 05By 30 Sep


### Submit


Attach your public repo, 1-minute video teaser, judging video (max 3 mins, public or unlisted), 1-sentence problem statement, chosen track, team snapshot, and required social post link.


Submissions close 30 September 2026 at 23:59 WIB. Submitting freezes the project immediately; the server decides whether a submission is on time.
