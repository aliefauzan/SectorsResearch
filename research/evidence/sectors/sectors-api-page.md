## Making your first authenticated API request to Sectors

### \#\#\# 1\. Upgrade to Sectors Insider

Through the Sectors API, you are two lines of code away from Indonesia's most comprehensive financial market data and stock research tools. Sectors Financial API is available on our Insider plans

### \#\#\# 2\. Obtain Sectors API Key

Once logged in with your Sectors account (Insider), navigate to API Key Management to generate a new API key. Include this API key in the header of your requests to authenticate and access the API (code snippets provided below).

### 3\. Code Example

#### Calling the Sectors API endpoints

Use your Sectors API Key to access data from Sectors. Explore [Sectors API Documentation](https://docs.sectors.app/) or API Playground to discover the available endpoints and sample responses.

PythonJavaScriptR

Copy code

```python
import requests

# Replace the URL with one from the Available Endpoints
url = "https://api.sectors.app/v2/.../"
api_key = "API key issued from the key management section"
headers = {"Authorization": api_key}

try:
    response = requests.get(url, headers=headers)
    response.raise_for_status()
    data = response.json()
except requests.exceptions.HTTPError as err:
    raise SystemExit(err)
```
